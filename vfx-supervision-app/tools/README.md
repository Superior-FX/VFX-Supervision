# Tools

Placeholder area for VFX-supervision utilities to be built out over time.
Not wired into the app UI yet — candidates to build here next:

- Shot/vendor budget calculator
- Framing & field-of-view calculator (sensor size, focal length, distance)
- LUT / CDL viewer
- Handle & turnover-frame-range calculator
- Aspect ratio / crop calculator

This app is intentionally independent of `element-library/` — no shared
code or data between the two.
