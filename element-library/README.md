# VFX Element Library

Standalone toolkit for indexing, browsing, and auditing a VFX stock-element
library (fire, smoke, sparks, blood, textures, etc.). This folder is
self-contained — copy it wholesale to any machine that needs to browse or
maintain the library.

## Contents

- `ingest.py` — scans configured source folders, generates JPEG thumbnails
  and H.264 proxy clips via ffmpeg, extracts metadata, and writes a master
  `index.json`.
- `browser.py` — PySide6 desktop GUI for browsing the library built from
  `index.json` (category filters, search, hover-preview video, thumbnails).
- `audit_library.py` — recursively scans a folder and reports file counts,
  sizes by category/extension, and image sequences with missing frames.
  Writes `audit_report.csv`, `audit_sequences.csv`, `audit_singles.csv`, and
  `audit_summary.txt`.
- `output/` — generated by the scripts above (thumbnails index, audit
  reports). Gitignored — regenerate it on each machine, don't commit it.

## Requirements

- Python 3.9+
- `pip install -r requirements.txt` (installs PySide6)
- [ffmpeg](https://ffmpeg.org/) + ffprobe available as binaries — `ingest.py`
  shells out to them for thumbnails/proxies

## Setup on a new machine

1. Copy this entire `element-library/` folder to the new machine.
2. `pip install -r requirements.txt`
3. Open `ingest.py` and edit the `CONFIG` section at the top to match this
   machine's paths:
   - `LIBRARY_ROOT` — path to the root of the element library
   - `FFMPEG` / `FFPROBE` — paths to your local ffmpeg/ffprobe binaries
   - `SOURCE_FOLDERS` — which subfolders under `LIBRARY_ROOT` to scan
4. Open `browser.py` and update `INDEX_PATH` to match `LIBRARY_ROOT` /
   `_LIBRARY_DATA` / `index.json` from step 3 (it must point at the same
   `index.json` that `ingest.py` writes).
5. Run the ingest once to build the index and generate thumbnails/proxies:
   ```
   python ingest.py
   ```
6. Launch the browser:
   ```
   python browser.py
   ```

## Auditing a library

```
python audit_library.py "D:/Your/Elements/Folder"
```

Produces a summary report plus CSVs in the current directory (move or point
them at `output/` as you prefer — they're gitignored either way).
